# 2026 special votes projection site

An interactive explainer for `project_specials.py` and `project_electorates.py`,
served at https://czlee.nz/elections/2026-projection/. A static SvelteKit site
(adapter-static, every page prerendered) with D3 for scales.

## Data

The JSON in `src/lib/data/<base>/` is generated by `../export_site_data.py` and
committed (CI can't regenerate it). There's one folder per base year (the past
election whose special votes are applied): 2023 is served at the root, the
others under their year (`/2020/`, `/2017/`); see `src/lib/bases.js`. After
changing the projection, from the repository root:

```
python3 project_specials.py
python3 project_electorates.py
python3 export_site_data.py
python3 project_specials.py --base 2020
python3 export_site_data.py --base 2020
python3 project_specials.py --base 2017
python3 project_electorates.py --base 2017   # after concordance.py --base 2017 (venv)
python3 export_site_data.py --base 2017
```

## Social previews

Every page has Open Graph/Twitter tags (set in `src/routes/+layout.svelte` from
`src/lib/server/og.js`) and a 1200×630 card at `og.png` next to it, which is
prerendered by an `og.png/+server.js` endpoint: an SVG drawn with the same
horseshoe component, converted to PNG with resvg using the Fontsource DM Sans
files. The image URL carries a hash of the card's data, so social platforms
refetch it when the numbers change. To see a card, build and open
`build/og.png` or `build/electorate/<slug>/og.png`.

## Develop

Node version is in `../.nvmrc` (`fnm use` or `nvm use`).

```
npm install
npm run dev        # http://localhost:5173/elections/2026-projection/
npm run check      # svelte-check
npm run build      # writes build/
npm run preview
```

Pushing to `main` deploys via `.github/workflows/pages.yml`.
