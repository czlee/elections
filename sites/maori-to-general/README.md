# 2026 with no Māori electorates

A small explainer for `maori_to_general.py`: what the 2026 preliminary
electorate results would have been with no Māori electorates, if every
Māori-roll voter had voted in the general electorate for their area. Served at
https://czlee.nz/elections/maori-to-general/. A static SvelteKit site, built
like `../2026-projection/` (and sharing its design, with copies of its components).

## Data

The JSON in `src/lib/data/` is generated by `../../export_maori_site_data.py` and
committed (CI can't regenerate it). From the repository root:

```
python3 download.py                    # results/2026-prelim/
python3 download_maori_places.py       # voting-place files for electorates 65–71
python3 maori_to_general.py            # prints the result
python3 export_maori_site_data.py      # writes this site's JSON
```

`src/lib/data/electorates-2025.topo.json` is a copy of the projection site's
map (`../../export_boundaries.py`).

## Develop

Node version is in `../../.nvmrc`.

```
npm install
npm run dev        # http://localhost:5173/elections/maori-to-general/
npm run check
npm run build      # writes build/
```

Pushing to `main` deploys both sites via `../../.github/workflows/pages.yml`.
`DRAFT` in `src/lib/config.js` adds a DRAFT banner and asks search engines not
to index the site; set it to `false` to publish for real.
