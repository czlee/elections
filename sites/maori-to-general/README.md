# 2026 with no Māori electorates

A small explainer for `scripts/maori-to-general/maori_to_general.py`: what the 2026 preliminary
electorate results would have been with no Māori electorates, if every
Māori-roll voter had voted in the general electorate for their area. Served at
https://czlee.nz/elections/maori-to-general/. A static SvelteKit site, built
like `../2026-projection/` (and sharing its design, with copies of its components).

## Data

The JSON in `src/lib/data/` is generated by `../../scripts/maori-to-general/export_maori_site_data.py` and
committed (CI can't regenerate it). From the repository root:

```
python3 scripts/download.py                    # data/elections/2026-prelim/
python3 scripts/maori-to-general/download_maori_places.py       # voting-place files for electorates 65–71
python3 scripts/maori-to-general/maori_to_general.py            # prints the result
python3 scripts/maori-to-general/export_maori_site_data.py      # writes this site's JSON
```

`src/lib/data/electorates-2025.topo.json` is a copy of the projection site's
map (`../../scripts/export_boundaries.py`).

## Social previews

Every page has Open Graph/Twitter tags (set in `src/routes/+layout.svelte` from
`src/lib/server/og.js`) and a 1200×630 card at `og.png` next to it, prerendered
by an `og.png/+server.js` endpoint: an SVG drawn with the same horseshoe
component, converted to PNG with resvg using the Fontsource Figtree files. The
image URL carries a hash of the card's data, so social platforms refetch it
when the numbers change. To see a card, build and open `build/og.png` or
`build/electorate/<slug>/og.png`.

## Develop

Node version is in `../../.nvmrc`.

```
npm install
npm run dev        # http://localhost:5173/elections/maori-to-general/
npm run check
npm run build      # writes build/
```

Pushing to `main` deploys both sites via `../../.github/workflows/pages.yml`.
`DRAFT` in `src/lib/config.js` adds a DRAFT banner and asks search engines not
to index the site. It's off (`false`): the site is public.
